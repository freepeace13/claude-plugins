# Article template

Fields, taken from Porch's `create-article` / `update-article` tools:

| Field | Limit |
|---|---|
| `title` | required, 160 characters max |
| `slug` | from the brief, letters, numbers, dashes and underscores, 160 max |
| `excerpt` | 320 max, shown on cards |
| `seo_title` | 70 max |
| `seo_description` | 320 max |

Structure of the body:

1. An opening paragraph that states the thesis. No heading above it.
2. `##` sections that follow the brief's outline, in order, using its headings.
3. Code blocks and tables only where they carry a fact.
4. End when the last section is done. No wrap-up paragraph.

Default length 700 to 1,100 words unless the brief says otherwise.
